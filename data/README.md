# Dataset

## Dataset Used

This project uses the xBD / xBD-S12 dataset for satellite-image-based
building damage assessment.

The dataset provides pre-disaster and post-disaster satellite imagery
along with building damage information.

## Damage Categories

The project focuses on four damage classes:

- No Damage
- Minor Damage
- Major Damage
- Destroyed

## Dataset Modalities

The xBD-S12 dataset provides satellite imagery from:

- Sentinel-1
- Sentinel-2
- Sentinel-2 TCI

The dataset patches are provided at 128 × 128 pixels.

## Data Storage

Large raw and processed datasets will not be uploaded to this GitHub
repository.

The local dataset will be stored inside:

data/raw/

Processed data will be stored inside:

data/processed/

## Dataset Preparation

Dataset preparation and preprocessing scripts will be added to the
project as development progresses.
